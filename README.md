# Data Analytics Portfolio

Hi, I’m Angelica Jose, a licensed Chemical Engineer with 7+ years of experience in Research and Product Development, manufacturing, Lean Six Sigma, and process improvement.

This portfolio showcases my transition into data analytics using SQL, Power BI, Excel, and business analysis. The projects are inspired by real manufacturing and product development problems, but all data used is anonymized or synthetic for confidentiality.

## Projects

### 1. NPD Portfolio Analytics
A SQL and Power BI project analyzing new product development projects, trial costs, project status, development timelines, project ranking, and RPD specialist performance.

**Tools used:** SQL Server, Power BI, Excel  
**Skills shown:** SQL joins, views, aggregation, ranking, DAX, dashboard design, business insights

### 2. Scrap Reduction Dashboard
A Power BI dashboard analyzing scrap generation, machine-level performance, before-and-after improvements, cost impact, and potential savings.

**Tools used:** Power BI, Excel, Lean Six Sigma  
**Skills shown:** KPI analysis, cost savings calculation, process improvement, dashboard storytelling

## Data Privacy Notice

All datasets used in this portfolio are anonymized or synthetic. No confidential company data, proprietary formulas, customer information, supplier information, internal records, or actual company files are included.
