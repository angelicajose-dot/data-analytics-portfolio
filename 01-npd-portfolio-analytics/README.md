# NPD Portfolio Analytics

## Project Overview
This project analyzes New Product Development portfolio performance using SQL Server and Power BI. It focuses on project status, trial investment, development timelines, project ranking, and RPD specialist workload.

## Business Problem
In manufacturing R&D, multiple projects may run at the same time. This makes it important to monitor project progress, trial costs, resource allocation, and development efficiency.

## Tools Used
- SQL Server
- Power BI
- Excel

## Key Metrics
- Total Projects
- Total Trials
- Total Investment
- Investment by Project Status
- Top 10 Highest Investment Projects
- Development Timeline
- RPD Specialist Performance

## SQL Skills Demonstrated
- INNER JOIN
- GROUP BY
- SUM, AVG, COUNT
- CASE WHEN
- RANK and ROW_NUMBER
- SQL Views
- Running Totals

## Power BI Skills Demonstrated
- Data modeling
- DAX measures
- KPI cards
- Bar charts
- Donut charts
- Drill-through page
- Dashboard storytelling

## Data Privacy
This project uses synthetic and anonymized sample data. It does not contain actual company records, proprietary product information, internal formulas, or confidential business data.
