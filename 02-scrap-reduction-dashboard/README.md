# Scrap Reduction Dashboard

## Project Overview
This project analyzes scrap generation in a manufacturing process and shows how data can support process improvement, cost reduction, and operational decision-making.

## Business Problem
Scrap generation increases production cost and reduces process efficiency. This dashboard helps identify major contributors to scrap and estimate potential savings from improvement actions.

## Tools Used
- Power BI
- Excel
- Lean Six Sigma

## Key Metrics
- Total Scrap
- Scrap Cost
- Scrap by Machine
- Scrap by Category
- Before vs After Performance
- Estimated Annual Savings

## Skills Demonstrated
- KPI tracking
- Cost savings analysis
- Before-and-after comparison
- Manufacturing process analysis
- Dashboard design
- Business insight generation

## Business Impact
The original improvement project resulted in approximately ₱1.16 million in annual savings. The dashboard version uses anonymized or synthetic sample data for portfolio purposes.

## Data Privacy
This project does not include actual company production data, machine identifiers, product names, internal cost structures, or confidential records.
